## [v0.2.0] - 2026-10-04 ([`4f8fe20`](https://github.com/grokify/gogrype/commit/4f8fe20))

### Highlights

- Grype output now converts to the shared [findingspec](https://github.com/plexusone/findingspec) IR — `GrypeOutputJSON.Findings` / `Match.ToFinding` produce `findingspec.Finding` with typed CVSS and fix state, CVE extraction, and container-vs-SCA typing
- The `github.com/grokify/govex` dependency is removed entirely; findingspec is the sole normalized vulnerability output (breaking)
- New `flatjson` package parsing the Grype/Anchore flat-JSON image-inventory-by-vulnerability export with per-file and aggregate severity statistics

### Added

- `GrypeOutputJSON.Findings(FindingSpecOptions)` and `Match.ToFinding(FindingSpecOptions)` convert Grype matches to `findingspec.Finding` (security domain), with `FindingSpecOptions` for image/digest/repo context ([`4f8fe20`](https://github.com/grokify/gogrype/commit/4f8fe20))
- `flatjson` package: parse Grype/Anchore flat-JSON exports (`File`, `Files`, `Results`, `Stats`) plus a `cmd/parse` CLI taking `-file` or `-dir` ([`94f711d`](https://github.com/grokify/gogrype/commit/94f711d))

### Removed

- **Breaking:** `GrypeOutputJSON.GoVEXes()` and `Match.GoVex()` are removed along with the `github.com/grokify/govex` dependency. Use `Findings` / `ToFinding`, which return findingspec types ([`c4c8c4f`](https://github.com/grokify/gogrype/commit/c4c8c4f))

### Dependencies

- _3 dependency updates_

### Documentation

- Remove the discontinued Go Report Card shield from `README.md` ([`67e1cc3`](https://github.com/grokify/gogrype/commit/67e1cc3))
